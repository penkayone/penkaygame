# Penkaygame

Премиальный интерактивный лендинг для iGaming-хаба. Одностраничный сайт на чистом HTML/CSS/JavaScript без сборки и зависимостей. Презентует подборку популярных казино-форматов (Crash, Mines, Plinko, Live Dealer, слоты, аркада Chicken Road / Tower Rush) и ведёт трафик по партнёрским ссылкам на казино-платформу 1Win и Telegram-канал с бонусами.

## О чём проект

Это не игра в прямом смысле — играть на самом сайте нельзя. Это **конверсионный landing hub**: посадочная страница, оформленная как кинематографичное казино-лобби, которая прогоняет пользователя по сценарию «посмотрел → выбрал формат → ушёл по партнёрской ссылке регистрироваться».

Визуальная метафора — «казино road trip»: куриный персонаж бежит по неоновой дороге, собирает монеты и доходит до лобби с игровыми карточками. Дорога анимируется по скроллу, фон оживляется canvas-сценой с плавающими фишками и картами, при наведении карточки наклоняются (3D tilt), а при включённом звуке проигрываются сгенерированные через Web Audio API казино-щелчки.

Целевая аудитория — мобильный трафик в iGaming-вертикали. Дизайн mobile-first, CTA крупные, на видном месте, с явным указанием 18+.

## Стек

- **HTML5** — семантическая разметка, ARIA-атрибуты для доступности.
- **CSS3** — кастомные свойства (CSS variables), Grid, Flexbox, keyframe-анимации, scroll-driven progress через `--road-progress`. Один большой `style.css` (~3000 строк), отдельный `reset.css`.
- **Vanilla JavaScript** (IIFE, без модулей и фреймворков) — canvas-фон, Web Audio API для синтеза звуков, IntersectionObserver для scroll-reveal, requestAnimationFrame для анимаций, pointer-события для 3D-наклона карточек.
- **Inline SVG** — иконки игр и анимированный куриный персонаж.
- **Никаких внешних зависимостей**, никакого npm-билда. `package.json` существует, но используется только как маркер проекта.

## Секции лендинга

1. **Hero** — заголовок, две CTA-кнопки (`Explore games`, `Telegram bonuses`), орбитальная композиция с floating-чипами и значением мультипликатора `x18.72`.
2. **Ticker** — бегущая лента с названиями форматов (Crash, Mines, Plinko, Live, Megaways и т.д.).
3. **Road story** (`#road`) — sticky-секция с куриным персонажем, бегущим по неоновой дороге; прогресс привязан к скроллу, по ходу собираются монеты и проигрываются coin-звуки.
4. **Games** (`#games`) — сетка из 6 карточек-форматов с уникальной анимированной арт-композицией внутри каждой (ракета, плитки мин, плинко-шарик, рулетка, барабаны, мини-курица). Каждая карточка — внешняя партнёрская ссылка.
5. **Experience** (`#experience`) — три плитки про фишки лендинга (3D-ощущение, аудио, mobile-first).
6. **Guide** (`#guide`) — три шага пользователя: открыть бонус, выбрать формат, играть ответственно.
7. **Footer** — дисклеймер 18+, Telegram и кнопка `Share` (Web Share API с фолбэком на копирование в буфер обмена).

## Интерактивные фичи

- **Canvas-фон** (`stageCanvas`) — постоянная анимация: 26 вращающихся фишек и 8 плавающих карт, эллиптические орбиты, реакция на `devicePixelRatio` и ресайз.
- **Web Audio API** — все звуки (`chip`, `rocket`, `drop`, `spin`, `slot`, `win`, `coin`) синтезируются на лету из осцилляторов и шума. Никаких mp3-файлов. По умолчанию звук выключен (autoplay-политика браузеров), включается кнопкой в шапке.
- **Scroll-driven road progress** — позиция курицы и связанные эффекты вычисляются из `getBoundingClientRect` секции дороги, обновление через `requestAnimationFrame`.
- **3D tilt** — карточки с `data-tilt` наклоняются за курсором (только на устройствах с `hover: hover and pointer: fine`).
- **Custom cursor orbit** — кольцо, следующее за указателем на десктопе.
- **Scroll-reveal** — элементы с классом `.reveal` появляются через `IntersectionObserver` с прогрессивной задержкой.
- **Share** — `navigator.share` с фолбэком `navigator.clipboard.writeText` и тостом `Link copied`.
- **`prefers-reduced-motion`** — учитывается: при включённой опции canvas-анимация не запускается.

## Как открыть

Сайт статичный, билд не нужен. Достаточно открыть `index.html` в браузере.

Для корректной работы при разработке (особенно если будут добавляться fetch-запросы или модули) лучше запустить локальный сервер из корня проекта, например:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Звук выключен по умолчанию — нажми кнопку `Sound off` в шапке, чтобы включить казино-аудио.
