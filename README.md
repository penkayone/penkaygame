# Penkay Games Landing

Небольшой одностраничный сайт-лендинг для промокода и быстрых переходов на игры по реферальным ссылкам.

---

## Что это за сайт и для чего он нужен

**Penkay Games** — это “хаб-страница”, где пользователь:
- видит основной оффер/промокод;
- выбирает нужную игру и переходит по реферальной ссылке;
- при необходимости открывает инструкции по регистрации и поиску игры.

**Цель страницы:** сократить путь пользователя до действия (1 страница → 1 клик → игра) и повысить конверсию переходов по реферальным ссылкам.

---

## Что мы сделали сегодня

### 1) Собрали стабильную вёрстку “как на макете”
- Сверстали структуру страницы: верхняя панель (Subscribe/Share), hero-зона, кнопки игр, блок инструкций.
- Настроили фиксированную “каркасную” ширину и отступы так, чтобы дизайн выглядел одинаково на разных экранах.

### 2) Сделали игровые кнопки, которые не ломаются
- Добавили аватарки (иконки игр) слева в каждой кнопке.
- Сделали аватарки круглыми (`border-radius: 50%`) и зафиксировали их размер.
- Сделали кнопки стабильной формы: фикс высоты, аккуратные отступы, без “раздувания” от padding.
- Отцентровали текст внутри кнопки так, чтобы он выглядел ровно как в примере.
- Добавили подпись под названием игры: **“Click to go to the game”**.

### 3) Реализовали инструкции (Accordion)
- Добавили 2 раскрывающихся блока:
  - **⁉️ HOW TO REGISTRATE ⁉️**
  - **⁉️ HOW TO FIND A GAME? ⁉️**
- При клике показываются подготовленные скриншоты.
- Стрелка по умолчанию смотрит вниз и поворачивается при открытии (аккуратно и без скачков вёрстки).

### 4) Сделали верхние кнопки Subscribe и Share
- **Subscribe** — ссылка (ты можешь вставить свой URL/назначение).
- **Share** — кнопка “поделиться ссылкой”: если браузер поддерживает — открывается системное меню share, если нет — ссылка копируется в буфер.
- Добавили лёгкий плавный hover/active эффект (без резких анимаций).

### 5) Подготовили импорт картинок (текст как изображения)
- Заголовки/надписи можно заменять на изображения (PROMOCODE / GAMES / INSTRUCTIONS).
- Картинки ограничены по ширине и не “растягиваются” на больших экранах.

## Что и где менять

### Реферальные ссылки
В `index.html` у каждой кнопки игры меняется `href`:
```html
<a href="https://your-ref-link.com" target="_blank" rel="noopener">...</a>
````

### Картинки заголовков/инструкций

Меняешь `src` у `<img>`:

```html
<img src="assets/images/instructions-title.png" alt="">
```
